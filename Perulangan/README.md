### Perulangan

Program latihan yang menggunakan perulangan dan percabangan untuk mengolah data siswa.

Program ini akan:

- Meminta jumlah siswa
- Meminta nama siswa
- Meminta nilai siswa
- Menentukan grade berdasarkan nilai
- Menentukan status lulus atau tidak lulus

Yang dipelajari:

- Perulangan `for`
- Percabangan `if`, `elif`, dan `else`
- Input pengguna
- Pengolahan data berdasarkan kondisi
