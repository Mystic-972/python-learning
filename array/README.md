# Array Nilai

Program sederhana untuk menyimpan dan mengolah 5 nilai menggunakan list di Python.

Program ini dibuat sebagai latihan untuk memahami penggunaan list, perulangan, percabangan, dan operasi dasar pada data.

## Fitur

Program akan:

- Meminta 5 nilai dari pengguna
- Menyimpan nilai ke dalam list
- Menampilkan kembali nilai yang telah dimasukkan
- Menghitung jumlah data
- Menghitung nilai rata-rata
- Mencari nilai tertinggi
- Mencari nilai terendah

Masukkan nilai ke-1 : 80
