
# Data Record Mahasiswa

Program sederhana untuk menyimpan dan mengolah data mahasiswa menggunakan Python.

Program ini merupakan latihan untuk memahami penggunaan `list`, `dictionary`, `function`, perulangan, dan percabangan dalam Python.

## Fitur

Program akan:

- Meminta jumlah mahasiswa
- Memasukkan NIM dan nama mahasiswa
- Memasukkan nilai tugas, UTS, dan UAS
- Menghitung nilai akhir
- Menentukan grade berdasarkan nilai akhir
- Menampilkan seluruh data mahasiswa dalam bentuk tabel

## Ketentuan Grade

| Nilai Akhir | Grade |
|------------:|:-----:|
| 80 - 100 | A |
| 70 - 79 | B |
| 60 - 69 | C |
| 50 - 59 | D |
| < 50 | E |

Nilai akhir dihitung menggunakan rumus:

```text
Nilai Akhir = (Tugas + UTS + UAS) / 3
