
# Fungsi

Program latihan untuk memahami penggunaan fungsi (`function`) di Python.

Program yang ada di folder ini menggunakan fungsi untuk menghitung luas beberapa bangun datar.

## Program

### Hitung Luas Bangun Datar

Program menyediakan beberapa pilihan untuk menghitung luas:

- Luas Segitiga
- Luas Persegi Panjang
- Luas Lingkaran

Program juga dapat digunakan kembali untuk menghitung luas bangun lain tanpa harus menjalankan ulang program.

## Contoh

```text
========================================
  Program Menghitung Luas Bangun Datar
========================================
1. Luas Segitiga
2. Luas Persegi Panjang
3. Luas Lingkaran
========================================
Pilih menu (1-3): 1

Masukkan panjang alas segitiga: 10
Masukkan tinggi segitiga: 5

Luas Segitiga adalah: 25.00
